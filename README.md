# Southern Idaho Muzzleloaders

Public website for the Magic Valley club. Shoshone and Twin Falls. Flintlock and percussion.

This repository is the full source. Grokbot: read [master/GROKBOT.md](master/GROKBOT.md) before changing anything. Facts and banned words are in [master/PARAMETERS.md](master/PARAMETERS.md).

## Run

```bash
npm install
npm run dev
```

Dev server: http://127.0.0.1:8080

```bash
npm run typecheck
npm run build
```

No accounts. No card charges. Newsletter, membership, and gifts stay on the visitor's phone until a real destination is connected.
